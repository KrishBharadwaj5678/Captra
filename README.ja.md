# 🎥 キャプトラ

キャプトラ は、**Webカメラを使って画像を撮影できる**最新の Web アプリケーションです。高度なコントロール機能も備えています。

![キャプトラ](https://github.com/KrishBharadwaj5678/Captra/raw/main/Captra_Demo.png)

## ✨ 機能

| 機能                  | 説明                                     |
| ------------------- | -------------------------------------- |
| 🎬 **Webカメラ撮影**     | Webカメラを使って直接写真を撮影できます。                 |
| 🔄 **カメラ切り替え**      | 前面カメラと背面カメラを切り替え可能（モバイル対応）。            |
| ⏱️ **カウントダウンタイマー**  | 撮影前にタイマーを設定できます（例: 3秒、5秒）。             |
| 🎨 **フィルター**        | リアルタイムでフィルターを適用し、スライダーで調整可能。           |
| 💫 **スムーズなアニメーション** | Framer Motion によるインタラクティブな UI アニメーション。 |
| 📱 **レスポンシブデザイン**   | デスクトップ・モバイルの両方で快適に動作します。               |

## 💻 インストール方法

### 1️⃣ リポジトリをクローンする

```bash
git clone https://github.com/KrishBharadwaj5678/Captra.git
```

### 2️⃣ フォルダへ移動する

```bash
cd Captra
```

### 3️⃣ 依存関係をインストールする

```bash
npm install
```

### 4️⃣ 開発サーバーを起動する

```bash
npm run dev
```

### 5️⃣ ブラウザでアプリを開く

ブラウザでアプリを開いて利用できます。
