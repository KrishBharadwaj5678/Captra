# 🎥 Каптра

Каптра — это современное веб-приложение, которое позволяет пользователям **делать снимки с помощью веб-камеры** с расширенными настройками управления.

![Каптра](https://github.com/KrishBharadwaj5678/Captra/raw/main/Captra_Demo.png)

## ✨ Возможности

| Функция                         | Описание                                                                            |
| ------------------------------- | ----------------------------------------------------------------------------------- |
| 🎬 **Съёмка с веб-камеры**      | Делайте фотографии напрямую с вашей веб-камеры.                                     |
| 🔄 **Переключение камеры**      | Переключение между фронтальной и задней камерой (поддержка мобильных устройств).    |
| ⏱️ **Таймер обратного отсчёта** | Установите таймер перед созданием снимка (например, 3с, 5с).                        |
| 🎨 **Фильтры**                  | Применяйте фильтры в реальном времени и настраивайте параметры с помощью слайдеров. |
| 💫 **Плавные анимации**         | Интерактивный интерфейс с анимациями на базе Framer Motion.                         |
| 📱 **Адаптивный дизайн**        | Отлично работает как на компьютерах, так и на мобильных устройствах.                |
