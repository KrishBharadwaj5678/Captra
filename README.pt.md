# 🎥 Captra

Captra é uma aplicação web moderna que permite aos usuários **capturar imagens usando sua webcam** com controles avançados.

![Captra](https://github.com/KrishBharadwaj5678/Captra/raw/main/Captra_Demo.png)

## ✨ Funcionalidades

| Funcionalidade                             | Descrição                                                                     |
| ------------------------------------------ | ----------------------------------------------------------------------------- |
| 🎬 **Captura pela Webcam**                 | Tire fotos diretamente da sua webcam.                                         |
| 🔄 **Trocar Câmera**                       | Alterne entre a câmera frontal e traseira (suporte para dispositivos móveis). |
| ⏱️ **Temporizador de Contagem Regressiva** | Defina um timer antes de capturar imagens (ex.: 3s, 5s).                      |
| 🎨 **Filtros**                             | Aplique filtros em tempo real e ajuste configurações usando sliders.          |
| 💫 **Animações Suaves**                    | Interface interativa aprimorada com animações do Framer Motion.               |
| 📱 **Design Responsivo**                   | Funciona perfeitamente em desktops e dispositivos móveis.                     |

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia              | Finalidade          |
| ----------------------- | ------------------- |
| ⚛️ **ReactJS**          | Framework frontend  |
| 🎞️ **Framer Motion**   | Animações suaves    |
| 📹 **MediaDevices API** | Acesso à webcam     |
| 🎚️ **RSuite Slider**   | Ajuste de filtros   |
| 🎨 **React Icons**      | Ícones da interface |

## 💻 Instalação

### 1️⃣ Clone o repositório:

```bash
git clone https://github.com/KrishBharadwaj5678/Captra.git
```

### 2️⃣ Navegue até a pasta:

```bash
cd Captra
```

### 3️⃣ Instale as dependências:

```bash
npm install
```

### 4️⃣ Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

### 5️⃣ Abra o aplicativo no navegador.
